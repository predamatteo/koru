## Why this exists separately

Software licences govern copying, not naming. Reserving the name is what
keeps a user who searches for "Koru" from installing something that merely
looks like it — which matters more than usual for an app that asks for
Accessibility, Device Admin and Usage Access permissions. Reputation is the
only thing standing behind that request, and reputation is attached to the
name.
